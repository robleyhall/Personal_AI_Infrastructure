# EXCLUDES — Corporate Bundle Blocklist with Reasoning
#
# This file documents what the corporate bundle deliberately does NOT ship
# and why. install-corporate.sh uses INCLUDES.txt as the source of truth
# (allowlist model), but this file is maintained alongside as rationale for
# Info Sec review and future-state decisions.

## Skills excluded from the corporate bundle

### Aphorisms
- Path: skills/Aphorisms/
- Reason: Database/aphorisms.md contains curated quotes from named authors
  (Feynman, Hitchens, Muhammad Ali, Bob Marley, Marcus Aurelius, etc.) without
  fair-use analysis or licensing review.
- Risk: Copyrighted content; IP team will flag.
- Future: If wanted, ship the skill scaffold with an empty DB and instruct
  the user to populate with their own or licensed content.

### Security/*
- Path: skills/Security/{Recon, WebAssessment, PromptInjection, AnnualReports, SECUpdates}/
- Reason: Active security tooling — external scanning, recon, prompt
  injection testing. Incompatible with corporate security policy.
- Risk: Could trigger IDS, fire EDR alerts, or violate external TOS.

### Investigation/*
- Path: skills/Investigation/{OSINT, PrivateInvestigator}/
- Reason: External OSINT queries; TOS and DLP concerns.
- Risk: Some investigation workflows fetch data from sites that log caller IP
  and may correlate to the corporate network.

### PAIUpgrade
- Path: skills/PAIUpgrade/
- Reason: Requires ANTHROPIC_API_KEY for the changelog tool; fetches YouTube
  channel metadata.
- Risk: External API + network egress; adds a supply-chain surface.
- Future: Consider after corp approves a pattern for API-key storage.

### Evals
- Path: skills/Evals/
- Reason: Degraded (cannot do cross-provider bake-offs in Copilot); heavy
  TypeScript tooling; workflows reference a non-existent EvalServer/cli.ts.
- Future: Tier 4 after a CLI dispatcher is built and the deps are reviewed.

### Delegation
- Path: skills/Delegation/
- Reason: Degraded (TeamCreate/TaskCreate/SendMessage unavailable in Copilot;
  falls back to parallel task calls). Complex and low value without full
  multi-agent support.

### CreateCLI
- Path: skills/CreateCLI/
- Reason: Writes new executables to ~/.pai/Bin/. Adds binary files to $HOME
  that Info Sec will want to review individually.
- Future: Include in a later tier with explicit per-CLI review workflow.

### USMetrics
- Path: skills/USMetrics/
- Reason: Irrelevant to corporate work.

### Parser
- Path: skills/Parser/
- Reason: Several workflows fetch external URLs (articles, YouTube, newsletters).
  Overlaps with Research but with less control over the allowlist.
- Future: Could ship if the fetch targets are restricted to the same allowlist
  as Research, but deferred for v1.

### Media/Remotion, Media/Art
- Path: skills/Media/{Remotion, Art}/
- Reason: Remotion is video composition (Claude-Code-specific tooling).
  Art is image generation that is API-gated.
- Media/Mermaid is technically safe (local diagram rendering) but deferred
  as low-value-for-initial-bundle.

### Aphorisms, Fabric branded patterns
- Path: skills/Fabric/Patterns/{ask_uncle_duke, create_clint_summary,
  write_hackerone_report, and other branded/named patterns}
- Reason: Reference specific personalities, brands, or third-party formats.
- Mitigation: Ship only the ~30 generic patterns listed in FABRIC_PATTERNS.txt.

## Runtime artifacts excluded

### Voice server
- Path: VoiceServer/
- Reason: Unnecessary for corporate use; audio output may conflict with corp
  audio policies; spawns a localhost bun process.
- Future: Tier 4 after separate security review.

### synthesize-learnings.ts
- Path: tools/synthesize-learnings.ts
- Reason: TypeScript tool requires `bun install` at install time. The
  companion synthesize-learnings.sh (bash wrapper) is also excluded for
  simplicity; can be added once `bun install` is approved.

### Voice/tab-title logic in sidecar
- Path: sidecar/pai-copilot (full version)
- Reason: References voice server and sets terminal tab title via OSC
  sequences. pai-copilot-corp (slim fork) strips both.

### .github/copilot-setup-steps.yml
- Path: .github/copilot-setup-steps.yml
- Reason: GitHub-hosted coding agent setup; not needed for personal corp use.
- Future: Could adapt for a corp-internal repo if/when PAI is used from the
  cloud coding agent.

### Claude Code compatibility files
- Path: CLAUDE.md.template, ~/.claude/* references, claude.yml, claude-code-review.yml
- Reason: The corporate bundle targets Copilot CLI only. Upstream Claude Code
  artifacts are preserved in the main repo for upstream compatibility but
  not installed by install-corporate.sh.
